プライバシーポリシー

最終更新日：2026年10月28日

Fumi（以下「本アプリ」）は、利用者のパソコン上で動作するメールアプリです。本アプリがどのような情報を扱い、どのように保護するかを説明します。

1. 扱う情報

  • 利用者が追加したメールアカウントのメールアドレスと表示名
  • メールサーバーから取得したメール（件名・差出人・宛先・本文・添付ファイルの情報）
  • メールサーバーへの接続に必要な資格情報（アプリ用パスワード、または Google のサインインで発行されるトークン）

2. 情報の使い道

これらの情報は、利用者自身がメールを読む・検索する・整理する・送信するためだけに使います。広告、分析、機械学習の学習、その他の目的には使いません。

3. 保存場所

  • メールは、利用者のパソコン内のデータベースに保存されます。
  • パスワードとトークンは、Windows の資格情報マネージャーに保存されます。
  • 本アプリの開発者が運営するサーバーはなく、情報が開発者や第三者に送られることはありません。通信先は Google（gmail.com、googleapis.com、accounts.google.com）と Apple（mail.me.com）のメールサーバーのみで、すべて TLS で暗号化されます。

4. Google ユーザーデータの取り扱い

本アプリは、Google でサインインした利用者のメールを読み書きするために、IMAP / SMTP 経由で Gmail にアクセスします（スコープ：https://mail.google.com/、openid、email）。

Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。Google ユーザーデータを第三者に販売・共有・転送することはなく、人がデータを読むこともありません。

5. 情報の削除

  • 本アプリの設定からアカウントを削除すると、そのアカウントの保存済みメールと資格情報がパソコンから削除されます。
  • 本アプリをアンインストールし、アプリのデータフォルダを削除すると、すべての情報が削除されます。
  • Google のアクセス許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

6. お問い合わせ

GitHub の Issues からご連絡ください。

7. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
